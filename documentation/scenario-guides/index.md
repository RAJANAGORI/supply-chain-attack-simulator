# Scenario guides

Learner walkthroughs, command cheat sheets, and the master scenario catalog. Zero-to-hero guides and quick-reference cards include a table of contents. Zero-to-hero guides also ship a Mitigation Playbook aligned with each scenario README.

Each zero-to-hero guide opens with a "Run this lab" box: Command Center (Labs → NN) and CLI (README commands).

| Document | Description |
|----------|-------------|
| [CATALOG.md](./CATALOG.md) | Master table - all 25 scenarios with links to README, DETECT, walkthrough, and module |
| [zero-to-hero/index.md](./zero-to-hero/index.md) | Step-by-step learner guides (25 walkthroughs) with TOC and mitigation playbooks |
| [quick-reference/index.md](./quick-reference/index.md) | Command cheat sheets for live teaching (CLI-oriented cards) with TOC |

Runtime labs live under [`scenarios/`](../../scenarios/) (README + Mitigation Playbook). Blue-team runbooks are `scenarios/*/DETECT.md`. Browser driver: [Command Center](../getting-started/COMMAND_CENTER.md).
